# Global agent rules

## Git workflow — PR first

- Never commit directly to `main` and never push to `main` unless the user explicitly asks for it in the current conversation.
- All changes go through branches and pull requests: create a branch, commit there, push the branch, open a PR.
- Split work into multiple PRs when chunks are logically separable.
- Conventional Commits style (`feat:`, `fix:`, `docs:`, `chore:`, …) everywhere.
